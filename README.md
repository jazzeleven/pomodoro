# Pomodoro

## Description

In order to maintain strict work discipline without relying on external applications, I decided to create a command-line tool to manage work sessions using the Pomodoro Technique.

## Features

- Customisable setting for work time and short/long breaks.
- Audio/Visual notifications OR session locking at the end of cycle.
- Option to pause or cancel a sesion.

**Planned features**

- Multithreads
- Graphical interface
